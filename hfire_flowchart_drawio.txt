HOW TO USE IN DRAW.IO (diagrams.net):
--------------------------------------------------------------------------------
METHOD 1 (Recommended - Fastest via Mermaid):
1. Open https://app.diagrams.net (draw.io).
2. Create a new blank diagram.
3. In the top toolbar, click "+" (Insert) -> "Advanced" -> "Mermaid".
4. Copy and paste the code from [SECTION 1: MERMAID CODE] below.
5. Click "Insert". Draw.io will automatically lay out and render the shapes.

METHOD 2 (Native draw.io XML):
1. In draw.io, click "Extras" in the menu bar -> "Edit Diagram".
2. Select all existing text and paste the code from [SECTION 2: DRAW.IO XML CODE].
3. Click "OK".
